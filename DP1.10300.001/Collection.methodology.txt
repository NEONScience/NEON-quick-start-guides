No field sampling is involved. NEON science staff maintain a master taxonomy list for each taxon type, based on the community-standard taxonomic authority for that group (e.g., the USDA PLANTS Database for plants, FishBase for fish), and assign each taxon a nativity status at each site from authoritative range references. Once a year, before NEON's annual data release, the backbone is regenerated: a new taxon table is written for each taxon type, a new location (nativity) table is written for each domain, and one record per site is added to the table for each taxon type (e.g., tax_small_mammal), pointing to those files through the taxonomyUrl and taxonomyLocationUrl fields. The processedDate field gives the date each version was generated. Each version is the backbone used to produce the observational data in the data release that follows it. Each table covers the sites where its taxon type has been sampled: the 47 terrestrial sites for beetles, birds, herpetofauna, mosquitoes, mosquito pathogens, and plants; 46 terrestrial sites for small mammals and ticks; all 34 aquatic sites for algae and macroinvertebrates; and 28 wadeable stream and lake sites for fish.
