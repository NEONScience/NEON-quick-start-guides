AIS Site Survey data are used to delineate hydrologic controls within the discharge cross-section to develop stage-discharge rating curves for each site. The elevation of each survey point can be converted to gauge height using the elevation of the staff gauge and the meter mark at which it was surveyed. Relative distance values can be calculated for each survey point using the northing and easting coordinates relative to a chosen reference point (e.g., the farthest survey point on the left side of the channel). The cross-section can then be visualized along a distance vs. gauge height axis, and the stage activation of each hydrologic control can be identified. For more information on how these data are used in rating curve development see NEON.DOC.005403. Publicly available code is also available at https://github.com/NEONScience/NEON-stream-discharge.
