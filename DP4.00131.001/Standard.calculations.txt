Stream morphology data are used to characterize the physical attributes of the stream and assess change over time. Spatial layers and Google Earth supported file types can be accessed via URL links in the geo_resultsFile table to create maps that delineate thalweg lines and edge of water boundaries, the distribution of geomorphic features, and the location of mapped cross-sections. Other defining metrics such as channel capacity, long-profile elevation, and the distribution of aquatic habitat types can be derived using data contained in the geo_transectBankfullWidths, geo_thalwegLongProfile, and geo_thalwegByHabitatID tables, respectively. Distribution curves can be constructed to assess changes in particle size distribution over time using data from the geo_pebbleFieldDatatable. Note that there are known issues when using Google Earth to view .KMZ maps. If you are experiencing problems viewing these morphology layers it may be helpful to turn off the habitat unit polygons in order to view the geomorphic feature polygons.
